# ООО «Горизонт»

Сайт строительной компании: благоустройство и ландшафт, земляные работы, дорожное строительство, наружные сети водоснабжения и канализации.

Тексты на сайте взяты из карточки организации и из согласованных формулировок. Банковские реквизиты не публикуются.

## Запуск

```bash
npm ci
npm run dev
```

Нужен Node.js 20.9 или новее. В `.nvmrc` указан Node 24.

Сайт собирается в статическую папку `out/` командой `npm run build`. Её можно залить в `public_html`.
