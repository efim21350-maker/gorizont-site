# ООО «Горизонт»

Сайт строительной компании: благоустройство и ландшафт, земляные работы, дорожное строительство, наружные сети водоснабжения и канализации.

Тексты на сайте взяты из карточки организации. Строки, которых в карточке нет, помечены «[уточнить]». Банковские реквизиты не публикуются.

## Запуск

```bash
npm ci
npm run dev
```

Нужен Node.js 20.9 или новее. В `.nvmrc` указан Node 24.

## Заявки

Форма «Обратная связь» работает как интерфейс и без почтового сервера: если SMTP не задан, человек видит по-русски, что письмо не отправлено, и контакты компании.

Переменные описаны в `.env.example`. Адреса для `CONTACT_TO`: ivangrosu127@gmail.com и buh.gorizont@internet.ru. Файл `.env` с паролями в репозиторий не кладётся.
